# TechQuest UI Skill

Use this skill to implement and refine the UI components, layout structures, and visual design of TechQuest.

## Context and Guidelines
- **Visual Source of Truth**: The Stitch design system is the visual source of truth.
- **Aesthetic Goal**: Premium futuristic student-tech aesthetic. Avoid generic Bootstrap looks, excessive glassmorphism, or excessive neon.
- **Principles**: Strong hierarchy, consistent spacing, polished cards, clear CTAs, consistent interactive states, and mobile-first approach.
- **Contrast**: Ensure contrast is accessible.
- **Responsibilities**: Formulate the HTML markup and DOM structure, ensuring alignment with Person 2's logic requirements.
