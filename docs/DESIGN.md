# Design Specification

## Typography
- Main Font: **Outfit** (via Google Fonts). Falls back to Sans-serif system fonts.

## Color Palette (Dark Theme)
- Primary Background: `#0a0a0c`
- Secondary Background: `#121217`
- Accent 1 (Indigo): `#6366f1`
- Accent 2 (Purple): `#a855f7`
- Primary Text: `#f3f4f6`
- Secondary Text: `#9ca3af`

## Design System Principles
- **Glassmorphism**: Use backing blurs (`backdrop-filter`) for headers and cards.
- **Smooth Transitions**: All animations and interactive hover events should follow cubic-bezier curves for premium feel.
