# Product Requirement Document (PRD)

## Project Overview
TechQuest is an interactive tech-driven event platform. The project aims to provide users with a clean, dynamic, and intuitive experience for discovering, registering for, and tracking tech events, hackathons, and workshops.

## Key Features
- **Landing / Home Page**: Introducing users to TechQuest.
- **Explore Events**: A discovery portal to search and browse the list of events.
- **User Passport**: A centralized profile detailing user achievements, badges earned, and participation history.
- **My Events**: A tracking panel showing registered and bookmarked events.

## Technical Constraints
- Pure HTML, CSS, JavaScript (no external runtime frameworks like React/Vue/Angular).
- Clean, responsive web design with modern aesthetics.
- Optimized for speed and performance.
