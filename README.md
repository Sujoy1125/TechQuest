# TechQuest

TechQuest is an interactive tech-driven event platform designed for modern tech enthusiasts. Explore hackathons, manage your event calendar, and track your achievements with a custom event passport.

## Running the Project
Since this is a client-side web application, you can view the application by opening `index.html` in any web browser, or by serving the files using a local development server (e.g., Live Server, `http-server`, or similar).
